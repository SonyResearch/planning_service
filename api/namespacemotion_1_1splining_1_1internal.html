◆ RemoveConstantPrepend()

drake::trajectories::PiecewisePolynomial< double > motion::splining::internal::RemoveConstantPrepend ( const drake::trajectories::PiecewisePolynomial< double > &  pp)

Removes any constant polynomial segments prepended to a piecewise polynomial.

Visits each segment and checks whether all of its polynomials are constant (i.e. only the degree-0 coefficient is nonzero). The first segment that contains a non-constant polynomial marks the start of the returned trajectory. If no constant prepend is found the original trajectory is returned unchanged.

Parameters
ppThe piecewise polynomial to process.
Returns
The piecewise polynomial with constant prepend segments removed.
