Detailed Description

This is an external class used for managing the construction of convex hulls of intersections, as well as determining trajectories through these convex hulls. The planner is constructed from an iris_regions_adapter from which the intersections vector must be provided. If no intersections are found int the intersections vector, null trajectories will be returned.

Parameters
iris_regions_adaptercontains the vector of intersections from which convex hulls are constructed
