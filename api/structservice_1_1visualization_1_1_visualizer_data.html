Detailed Description

Data required to spawn a given model in the Meshcat visualizer. Includes a reference to the model geometry (either from a full context or from a DMD), as well as some optional parameters for the visualizer. If no Meshcat parameters are provided, the visualizer will attempt to load from disk and, failing that, use defaults.
