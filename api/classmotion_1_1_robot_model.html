Build a robot model with meshcat visualizer from a drake model directives object.

Parameters
xml_filethe path to the xml file that contains the assets for the robot model
dmdthe model directives.
robot_meshcat_params[optional] the meshcat parameters for the robot model. If not provided, the robot model will not have a meshcat visualizer.
continuous_revolute_jointsthe list of continuous revolute joints expressed as a pair of model instance name and joint index.
implicit_parallelismif true, configure the collision checker to use implicit context parallelism (i.e., the collision checker will allocate contexts under-the-hood, instead of requiring explicit developer allocation and management).

Returns
true if all visual shapes are encapsulated by meshes, false otherwise.
Parameters
tolthe tolerance for the encapsulation check. The default value is 1e-3 meters.
Note
positive tolerance means that the collision shapes are interpreted as inflated, i.e. the visual shapes are allowed to be outside of the collision shapes by the given tolerance.
This function checks if all visual shapes are encapsulated by collision shapes, i.e. if the visual shapes are contained within the collision shapes.
