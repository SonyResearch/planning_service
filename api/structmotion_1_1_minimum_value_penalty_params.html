Detailed Description

Parameters used for minimum value penalty function. The minimum value penalty function is defined as: psi(x) = m * (exp(-gamma*x) - exp(-gamma*x0))/(1 - exp(-gamma*x0)), if x < x_0 psi(x) = 0, otherwise where

  • m > 0 is the value of the penalty function at x = 0
  • gamma is the decay rate of the penalty function
  • x_0 > 0 is the threshold value of the penalty function The function is convex for gamma > 0 and concave for gamma < 0. At gamma = 0, the function is not defined, but the limit as gamma -> 0 is psi(x) = M (1 - x/x_0), which is a linear function of x.
