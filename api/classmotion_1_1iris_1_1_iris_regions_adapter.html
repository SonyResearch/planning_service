Evaluates the intersection of an edge with a region.

Parameters
edgethe edge to check that is parameterized by two configurations q₁, q₂.
regionthe region to check.
Returns
If the edge intersects the region, then the pair of two numbers λ₁, λ₂ ∈ [0,1]. The set that is inside the region is given by {(1 - λ)q₁ + λq₂ | λ ∈ [λ₁, λ₂]}. If the edge does not intersect the region, then nullopt is returned.
