bool service::utils::ContextIsValid ( const PlanContext &  context)

Verify whether or not the information in the given plan context is valid and self-consistent. Specifically, checks that:

  1. DMD filenames match URDF filenames
  2. all Models contain geometry data
  3. all Models have the same package name
  4. context does not have null collision-checker
Parameters
contextTarget context
Returns
true if all conditions satisfied
false otherwise
