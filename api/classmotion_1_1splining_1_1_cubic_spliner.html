Add nodes to fix the spline resulting from the path: For each knot point, check if the spline violates constraints between this knot point and the previous one. If it does, add a knot point that is the average of these two knots and insert it in between them.

Parameters
wayptsmatrix of waypoints that generated the spline
q_samplematrix of sampled states from the spline
s_samplevector of s values for each sampled state from the spline
are_states_valid_vecVector containing the validity of each entry q_i in q_sample
Returns
The adjusted waypoints matrix with new points added
