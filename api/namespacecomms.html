void comms::set_transaction_id_from_context ( const grpc::ServerContext *  ctx)
inline

Extract the "transaction_id" key from the incoming gRPC request metadata and store it as the current thread's transaction ID. If the key is absent a fresh UUID is generated so that every request is always traceable.

Call this at the top of every gRPC service handler:

grpc::Status MyService::MyRpc(grpc::ServerContext* ctx, ...) {
comms::set_transaction_id_from_context(ctx);
...
}
