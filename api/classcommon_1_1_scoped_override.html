Detailed Description

template<typename T>
class common::ScopedOverride< T >

Class template to manage the lifetime of an override on an Overrideable instance. On construction, the ScopedOverride takes ownership of the Overrideable instance and optionally sets a new value. On destruction, the ScopedOverride restores the previous value and releases ownership.
