Detailed Description

template<typename T>
class common::Overrideable< T >

Class template to hold a value that can be overridden and restored. Useful for managing parameters or settings which a user may want to change temporarily and then revert back to the original value.

Intended to be used with ScopedOverride (see below) - without it, the value is effectively read-only. Users should be familiar with its std::optional-like semantics.
