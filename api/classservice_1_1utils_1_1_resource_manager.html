Detailed Description

template<typename RequestType, typename ResultType>
class service::utils::ResourceManager< RequestType, ResultType >

Class which manages the main compute resource (i.e., the "Draco") for planning and other algorithms, as well as computation of results using that resource. Concretely, owns ID-based lookup access to the resource, a queue to process new requests, and a runner to handle, and store the results of, threads of computation.
