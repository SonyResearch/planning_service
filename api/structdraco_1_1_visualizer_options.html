◆ display_trajectory_frequency

int draco::VisualizerOptions::display_trajectory_frequency
Initial value:
{
20}

The frequency at which the trajectory is displayed in the visualizer. This is the number of times per second the meshcat positions are updated. For example, if this is set to 20, the trajectory will be displayed using positions displayed at 50 ms intervals (1000 ms / 20 = 50 ms).

◆ wait_for_user_go_input_in_meshcat

bool draco::VisualizerOptions::wait_for_user_go_input_in_meshcat {false}
Warning
This option would put planning on hold until the user clicks the "Go" button in the meshcat visualizer. This is useful for debugging and visualization purposes, but it can be annoying if you want to run the planner without waiting for user input.
