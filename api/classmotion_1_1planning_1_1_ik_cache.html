std::vector< Eigen::VectorXd > motion::planning::IkCache::CalcClosestSeed ( const FrameRelativePoses &  frame_relative_poses,

Searches the IK cache for the closest seeds to a target pose and reference configuration. Two different algorithms are available and can be selected using the flag select_seed_via_two_steps.

Parameters
frame_relative_posesA vector of tuples containing pairs of frames and their relative poses.
q_referenceA reference configuration that determines idle arms as well as plays a role in the cost function.
angle_weightA weight for the angle difference in the cost function. The weight for translation is 1.
q_weightA weight for the configuration difference from the reference configuration.
num_seedsThe number of seeds to return. If -1, returns all seeds.
select_seed_via_two_stepsIf true, uses a two-step approach to find the closest seeds.
Returns
A vector of configurations, sorted by their cost function value.
