Detailed Description

Light wrapper class used to describe a convex hull. In our cases, all convex hulls are constructed from three regions or two intersections which share an intermediate region. In order to construct a convex hull through a convex set, two intersections must share a convex set.

Parameters
convex_hullthe convex hull being stored
start_indexindex of the edge convex set (must be smaller than end_index)
mid_indexthe index of the convex set that both intersections from which the convex hull was constructed share
end_indexthe other index of the edge convex set (must be larger than start_index)
add_indexthe index of the convex hull as a whole (order of construction)
