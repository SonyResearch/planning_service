double  tol = 1e-4 
)
inline

Returns true when two joint position vectors differ by more than tol in any single component (L-infinity norm).

Prefer this over isApprox for joint positions: isApprox uses a relative tolerance that behaves poorly near zero, whereas this checks an absolute dead-band appropriate for revolute/prismatic joints (default 0.1 mrad).
