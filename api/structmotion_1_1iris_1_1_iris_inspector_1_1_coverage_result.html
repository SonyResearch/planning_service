Detailed Description

Provides infomration on how the IRIS regions cover a specific set of configurations.

Field Documentation

◆ uncovered

int motion::iris::IrisInspector::CoverageResult::uncovered

The number of configurations that are not covered by the iris regions by either volume or visibility.

◆ violates_constraints

int motion::iris::IrisInspector::CoverageResult::violates_constraints

The number of configurations that violate the constraints. They do not count as uncovered.

◆ visibility_covered

int motion::iris::IrisInspector::CoverageResult::visibility_covered

The number of configurations that are covered by the visibility of the iris regions. If a configuration is visibility-covered, it means that all the points on the shortest line segment between the configuration and one of the iris regions satisfies the constraints.

◆ volume_covered

int motion::iris::IrisInspector::CoverageResult::volume_covered

The number of configurations that are covered by the volume of the iris regions. If a configuration is volume_covered, it means that it is inside at least one of the iris regions.
