Detailed Description

template<typename TService, typename TStub>
class comms::test::ServiceTest< TService, TStub >

Test fixture template used to test a given service against its corresponding stub. Given an autogenerated gRPC service MyGrpcService, the corresponding test fixture would have the form: class MyGrpcServiceTest : public ServiceTest<MyGrpcServiceImpl, MyGrpcService::Stub> {...}.

where MyGrpcServiceImpl is derived from MyGrpcService::Service.
