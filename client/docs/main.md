## Protocol Buffers (Protos)

Our system relies on Protocol Buffers (Protos) as a language-neutral, platform-independent way of serializing structured data. These definitions serve as the foundation for communication between services, ensuring consistency, performance, and scalability across platforms.  
📚 To explore the available message types, services, and more, please visit the [Protos API documentation](/protos/index.html).

## Planning Service

The Planning Service is a core component of our architecture, responsible for managing scheduling, coordination, and resource allocation logic. It provides a set of robust APIs to support complex workflows and decision-making processes. Whether you're building a high-level orchestration engine or a lightweight client, the Planning Service API is designed to support your needs efficiently.  
🔍 For detailed information about the available endpoints, usage examples, and integration guidelines, check out the [Planning Service API documentation](https://legendary-adventure-22ojg5v.pages.github.io/api/index.html).
